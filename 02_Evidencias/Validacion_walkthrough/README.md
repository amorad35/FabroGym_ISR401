# Validación Walkthrough

## Estado

Se realizaron **seis sesiones reales de validación mediante walkthrough**: tres con participantes de perfil técnico y tres con participantes de perfil no técnico.

Las sesiones fueron ejecutadas antes del registro OSF y constituyen evidencia empírica previa o formativa del estudio. No se presentan como datos confirmatorios preregistrados.
