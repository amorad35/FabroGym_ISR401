# FabroGym

Repositorio académico del Proyecto Fin de Curso de la asignatura
**Ingeniería de Requerimientos (ISR-401)** de la Universidad Técnica
Estatal de Quevedo.

## Descripción del proyecto

FabroGym es un sistema de gestión administrativa y operativa orientado
a apoyar los procesos internos de Garrosh Gym, ubicado en El Empalme.

El sistema contempla la gestión de clientes, membresías, pagos,
asistencias, rutinas, ventas, inventario, reportes administrativos y
comunicación interna.

## Estructura del repositorio

- `01_ERS/`: documento ERS/SRS, archivo LaTeX y referencias.

- `04_Trazabilidad/`: matrices de trazabilidad y priorización.
