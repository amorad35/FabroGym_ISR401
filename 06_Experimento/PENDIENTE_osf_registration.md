# Prerregistro OSF pendiente

El componente empírico de **FabroGym - Enfoque 3: Explicabilidad como Requisito No Funcional (RNF)** se encuentra en fase de preparación previa al registro en Open Science Framework (OSF).

A la fecha de esta versión, el repositorio no dispone todavía del comprobante oficial del registro OSF. Este archivo se mantiene como marcador documental temporal hasta que el registro haya sido formalizado y cuente con una URL persistente y sello temporal verificable.

Antes del registro OSF se realizaron **seis walkthroughs reales: tres con participantes técnicos y tres con participantes no técnicos**. Estas sesiones constituyen evidencia empírica previa/formativa del estudio y no se presentan como datos confirmatorios preregistrados.

El registro OSF será posterior a esas seis sesiones. Su finalidad es documentar transparentemente esta secuencia temporal y congelar las decisiones analíticas y las actividades de validación que todavía se encuentren pendientes, entre ellas el member checking final si aún no se ha ejecutado.

No se declaran nuevas rondas de walkthrough inexistentes ni se atribuyen al prerregistro actividades ya realizadas.

Una vez formalizado el registro, el comprobante correspondiente se conservará en:

```text
06_Experimento/osf_registration.pdf
```

En la misma actualización del repositorio, este archivo `PENDIENTE_osf_registration.md` dejará de ser necesario y podrá retirarse, manteniéndose la trazabilidad mediante el historial de Git y el registro oficial de OSF.
