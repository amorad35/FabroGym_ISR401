# Prompts y respuestas de LLM - no aplica

El estudio FabroGym no seleccionó un enfoque experimental basado en comparación o generación de requisitos mediante LLM. El ERS excluye IA/AA del alcance actual. Por ello, esta carpeta no contiene prompts, respuestas, parámetros de inferencia ni resultados de modelos.

No debe incorporarse contenido artificial para completar esta carpeta. Si el protocolo cambia, primero se requiere la adenda ética y el registro metodológico correspondiente.
