# ANONYMIZATION

## Objective
The replication package contains only public-zone materials suitable for open deposit. Direct personal identifiers and identifiable audiovisual evidence are excluded.

## Transformations and minimization
1. Interview transcripts use stable participant/session codes instead of personal names.
2. WALK sessions use only `WALK-TEC-*` / `WALK-NTEC-*` identifiers and anonymized roles/profiles.
3. Member-checking records use `MC-P01`, `MC-P02`, and `MC-P03`.
4. The questionnaire copy contains 70 responses and excludes the two empty direct-identification columns from the original form export.
5. Audio/video bytes, faces, voices, original signatures, ID numbers, personal emails, phones, IP addresses, original consents and the restricted encrypted container are not included.
6. Multimedia tables retain only non-content technical metadata required for integrity and reproducibility.

## Manual review performed for this release candidate
The release was scanned for forbidden media/archive extensions and common direct-identifier patterns. This technical scan is only a safeguard; the team remains responsible for a final human privacy review before Zenodo publication.
