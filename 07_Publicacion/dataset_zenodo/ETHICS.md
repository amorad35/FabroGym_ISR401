# ETHICS

## Ethical and legal scope
FabroGym is an academic ISR-401 project in Ecuador. The open replication package applies data minimization, pseudonymization and separation between public [P] and restricted [R] evidence, consistent with the project ethical documentation and Ecuadorian personal-data-protection requirements.

## Restricted evidence
Original consents, signatures, identity documents, identifiable audio/video, and other restricted evidence are **not included** in this Zenodo package. Those materials remain in the separately controlled restricted evidence workflow required by the course.

A13 and the second-round addendum must not be described as signed unless the team has actually obtained the signatures; this package does not assert signatures that have not been verified.

## WALK chronology and preregistration
The six WALK sessions occurred before the OSF registration published on 2026-08-29. They are therefore described as pre-registration/formative evidence. The deviation is disclosed in the OSF-deviations files.

## Member checking
Member checking occurred and is documented using `MC-P01`, `MC-P02`, and `MC-P03`. There is no audiovisual recording of that activity. No recording is created or implied by this package.

## AI/recommender scope
The recommendation/AI component is proposed. The package does not state that machine-learning recommendations were functionally implemented or empirically evaluated when that did not occur.
